# 幼儿园管理系统（若依 RuoYi-Vue 3.9.2 整合版）

将自研的 Spring Boot 幼儿园管理系统整体迁移到 **RuoYi-Vue 3.9.2（Spring Boot 3 + Vue 3 + Element Plus）** 骨架之上：
业务功能与演示数据保留，权限、菜单、字典、操作日志、代码生成等能力全部复用若依原生实现。

- 本仓库（若依版）：<https://github.com/L-49/kids-care-system-ruoyi>
- 姊妹仓库（自研版，同一套业务规则）：<https://github.com/L-49/kids-care-system>

| 层次 | 选型 |
|---|---|
| 后端 | Spring Boot 3.5 + Spring Security + JWT + MyBatis XML + PageHelper（JDK 17） |
| 数据库 / 缓存 | MySQL 8.0（`kids_care`）+ Redis 5+（db 1） |
| 前端 | Vue 3.5 + Vite 6 + Element Plus 2.13 + Pinia + ECharts 5 |
| 脚手架 | RuoYi-Vue 3.9.2 / RuoYi-Vue3 3.9.2，遵循其 MIT 许可 |

## 快速开始

### 环境要求

| 依赖 | 要求 |
|---|---|
| JDK | **17**（不要用 21/23，JDK 23 起 Lombok 会静默失效） |
| Maven | 3.9.x |
| MySQL | 8.0 |
| Redis | 5+，`localhost:6379`，**database 1**（无密码） |
| Node.js | 18+（建议 20 / 22） |

### 1. 数据库与缓存

```bash
cd kids-care-ruoyi
mysql -uroot -p < sql/ry_20260417.sql          # 若依基础表 + 菜单（首次）
mysql -uroot -p < sql/kids_migrate_v1.sql      # 幼儿园业务表 + 演示数据
mysql -uroot -p < sql/kids_menu_v2.sql         # 业务菜单与角色授权（幂等，可重跑）
mysql -uroot -p < sql/kids_fix_v3.sql          # 已有库幂等增量：收权限、补字典、修脏数据
mysql -uroot -p < sql/kids_today_attendance.sql # 可选：补当天考勤，便于看板演示
```

数据源与 Redis 均支持环境变量覆盖：`DB_HOST` / `DB_PORT` / `DB_NAME` / `DB_USERNAME` / `DB_PASSWORD`。

### 2. 后端（8081）

```bash
cd kids-care-ruoyi
mvn -o -DskipTests install              # 首次或改过业务模块代码后必须执行
mvn -o -pl kids-admin spring-boot:run   # 或用 IDEA 运行 RuoYiApplication
```

Windows 下也可直接双击 `kids-care-ruoyi/启动后端.bat`（自动设置 JDK 17、编译、启动，带防重复启动判断）。

### 3. 前端（81）

```bash
cd kids-care-ruoyi-ui
npm install
npm run dev        # http://localhost:81，/dev-api 代理到 8081
```

Windows 下双击 `启动前端.bat`，或 `打开系统.url` 直接打开页面。
**只能通过 `http://localhost:81` 访问**，`file://` 方式打开 `dist/index.html` 会整页空白。

### 4. 账号（密码均为 `123456`）

| 账号 | 角色 | 数据范围 |
|---|---|---|
| `admin` | 园长 | 全部功能与全部数据 |
| `teacher` | 教师 | 业务数据可维护；教职工、收费只读；系统管理不可见 |
| `parent` | 家长（张建国） | 仅「工作台 + 我的孩子」，只能看到自己绑定的幼儿 |

> 登录页默认已预填 `admin / 123456`；验证码由 `sys_config` 的 `sys.account.captchaEnabled` 控制。
> 更细的启动排错（缓存、端口、菜单不显示等）见 [`kids-care-ruoyi/README.md`](kids-care-ruoyi/README.md)。

## 功能范围

工作台、幼儿档案（Excel 导入导出、调班、变更留痕）、班级管理（容量与满班）、教职工管理、课程排课、
考勤、请假审批、每周食谱（过敏标注、复制上周）、食材库存（出入库台账、低库存预警）、
收费管理（确认收款、欠费统计）、通知公告（草稿 / 定时 / 已发布 / 已撤回 四状态机 + 定向班级可见）、
数据报表、数据字典、操作日志、家长端「我的孩子」。

## 幼儿档案核心业务规则（v1.3 起）

1. **日期校验**（新增 / 修改 / Excel 导入三路同一套）
   - 出生日期、入园日期必填；
   - 出生日期不得晚于今天，且必须早于入园日期；
   - 按**入园日期**计算年龄，须满 3 周岁且未满 7 周岁（3~6 岁），否则拒绝并提示实际年龄。
2. **在园状态与时间绑定**
   - 状态不再允许手工指定：前端灰显只读，后端强制覆盖入参；
   - 入园日期晚于今天 → 离园（预约入园），当天及以前 → 在园；
   - 列表、详情、状态筛选、班级容量统计统一使用 `enroll_date > curdate()` 实时表达式，
     **预约到期自动转为在园，无需定时任务**。
3. **下载导入模板**：幼儿档案工具栏有独立「下载模板」按钮（导入对话框内的下载链接保留）。
4. **导入错误按行号返回**：Excel 表头按 `@Excel(name)` 文字匹配，失败行给出真实行号与原因。

演示用模板与含错误行的样例在 `演示素材/`，含 3~6 岁规则的失败用例说明。

## 已知限制

1. 在园状态完全由入园日期判定，「离园」仅表达「预约未到/未入园」；若要做退园业务，需单独增加退园日期字段。
2. 幼儿搜索仅支持姓名（后端 `ChildMapper.xml` 已有 `guardianPhone` 条件，前端未暴露输入框）。
3. Excel 导入不做去重，同名同电话重复导入会产生多条记录。
4. 公告定时发布由 `@Scheduled(cron = "0 * * * * ?")` 每分钟扫描，非 Quartz，最大延迟约 1 分钟。
